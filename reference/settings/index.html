    mgdio.settings¶

    Constants are shown with their default values. Environment variables read at import time: MGDIO_GOOGLE_PROFILE, MGDIO_WHOOP_REDIRECT_URI, MGDIO_LOG_LEVEL, MGDIO_NONINTERACTIVE. A .env file in the working directory is loaded first, which is also how a project-local MGDVAULT_PASSWORD reaches mgdvault; see Credential vault for the MGDVAULT_* variables.

    Package-wide settings: paths, scopes, vault keys, logging.

    Importing this module is idempotent and has these side effects:

    • loads .env (silent if absent); mgdvault also loads the nearest .env on its own, so a project-local MGDVAULT_PASSWORD works for both the mgdio and mgdvault CLIs,
    • ensures APP_DATA_DIR and GOOGLE_DATA_DIR exist, and
    • configures root logging once, only if no handlers are present yet (so library users keep control of their root logger).

    All paths use platformdirs so the package works without env vars on Windows, macOS, and Linux.

    Secrets (OAuth tokens, API keys) are not kept under APP_DATA_DIR. They live in the shared mgdvault <https://github.com/mdinunzio/mgdvault>_ credential vault under the mgdio/ namespace; the *_VAULT_KEY constants below name every secret mgdio reads or writes. Only non-secret artifacts (the Google OAuth client_secret.json) stay on disk.

    Provider-specific configuration is namespaced by prefix (GOOGLE_*, YNAB_*, WHOOP_*, ...).

    def google_vault_key(slug: str) -> str:
    """Return the per-profile vault key, ``mgdio/google/<slug>``."""
    return f"{GOOGLE_VAULT_PREFIX}/{slug}"
